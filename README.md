# Student Management System

A Python desktop application for managing student records.

## 📌 Project Description

The Student Management System is a desktop application developed using
Python and Tkinter. It allows users to add, search, update and delete
student records through a graphical user interface.

## 🚀 Features

- Add Student
- Search Student
- Update Student
- Delete Student
- Graphical User Interface
- Student record management

## 🛠️ Technologies Used

- Python
- Tkinter
- SQLite
- Git
- GitHub
